# CLAUDE.md — Matteo Giordani Portfolio

## Mission

Build the portfolio of **Matteo Giordani — SEO Specialist & Front-End Developer**.

The portfolio exists to attract freelance clients, primarily in Italy, by clearly communicating:

> **I build websites that rank, perform and convert.**

Supporting message:

> **I help businesses get found on Google.**

The core differentiator is that Matteo can both **diagnose SEO problems and work directly on the website to implement improvements**.

The portfolio must therefore communicate:

**SEO + Technical SEO + Front-End + Website Optimization**

Do not position Matteo as a generic SEO consultant or generic developer.

---

# Creative Direction

The website must feel:

- Apple-like
- premium
- minimal
- cinematic
- innovative
- technical
- precise
- intelligent
- experimental but controlled

Reference qualities:

- Apple product presentation
- Framer interaction design
- premium editorial design
- creative developer portfolios
- product visualization

Avoid:

- generic SaaS
- generic SEO-agency aesthetics
- generic developer portfolios
- AI-generated template aesthetics
- cyberpunk
- neon
- excessive gradients
- excessive glassmorphism
- random particles
- meaningless 3D
- excessive cards
- decorative animation without purpose

The design should feel expensive through **restraint, typography, spacing, composition and motion**.

---

# Central Concept

The core creative idea is:

> **The website builds itself while you scroll.**

The visitor should experience one continuous transformation:

```text
DISCOVER
↓
UNDERSTAND
↓
OPTIMIZE
↓
BUILD
↓
PERFORM
↓
CONVERT
```

The same website/browser object should evolve through the narrative.

Do not build six unrelated animated sections.

---

# Narrative

### 01 — Discover

Start with an elegant but unfinished website/browser.

Meaning:

> Being online isn't the same as being found.

### 02 — Understand

Introduce search intent, queries, keywords, content and information architecture.

Do not recreate Google's UI.

### 03 — Optimize

Reveal technical structure:

- semantic hierarchy;
- metadata;
- internal linking;
- indexability;
- technical SEO.

Do not create a conventional SEO dashboard.

### 04 — Build

The structure transforms into Front-End components.

Show concepts such as:

- components;
- layouts;
- HTML/CSS;
- responsive structure;
- UI.

Core message:

> **I don't stop at the audit. I can build the fix.**

This is a key positioning moment.

### 05 — Perform

The website becomes lighter, faster and more stable.

Use concepts such as:

- Core Web Vitals;
- rendering;
- loading;
- responsiveness;
- performance.

Never fabricate real scores.

### 06 — Convert

The website becomes a complete user experience.

Show:

- hierarchy;
- CTA;
- usability;
- user journey;
- conversion.

Core message:

> **A website shouldn't only rank. It should work.**

### 07 — Complete

The transformation becomes the bridge into:

- Services
- Selected Work
- About
- Insights
- Contact


Use a modern sans-serif.

Priorities:

1. strong large-scale typography;
2. premium technology/product feeling;
3. readability;
4. subtle experimental character.

Use fluid typography where appropriate.

Avoid futuristic fonts that damage professionalism.

# Motion

Motion should feel:

- smooth;
- physical;
- intentional;
- cinematic;
- restrained.

Use:

- scroll-driven transforms;
- pinned scenes;
- scale;
- opacity;
- perspective;
- depth;
- controlled rotation;
- text reveals;
- object morphing;
- background transitions.

Avoid:

- bounce;
- random floating;
- excessive parallax;
- constant movement;
- aggressive cursor effects.

Never hijack native browser scrolling.

The visitor must be able to scroll normally, reverse direction and use keyboard, touch and trackpad.

---

# 3D

Use restrained 3D only when it strengthens the narrative.

Good objects:

- browser windows;
- website frames;
- page layers;
- UI components;
- search objects;
- performance objects;
- subtle digital twin.

Avoid unrelated decorative 3D.

A digital representation of Matteo may appear, but without an accurate reference image do not invent a photorealistic likeness. Prefer abstract/minimal/digital treatment.

# Development Workflow

Before coding:

1. inspect the repository;
2. inspect `package.json`;
3. inspect the current framework;
4. inspect existing components;
5. inspect available assets and fonts;
6. identify reusable code.

Then:

1. establish visual foundation;
2. build hero;
3. build continuous narrative;
4. build semantic sections;
5. test desktop;
6. adapt mobile;
7. review as Creative Director;
8. iterate.

Do not ask unnecessary questions. Make strong design decisions from the brief.

---

# Quality Bar

Before considering the mockup successful, evaluate:

### Premium
Does it feel expensive without being flashy?

### Apple-like
Does it use restraint and product-style presentation without copying Apple?

### Innovative
Is the scroll transformation memorable?

### Personal
Does it feel like Matteo?

### Professional
Would a business owner trust Matteo with their website?

### Differentiated
Is SEO + Front-End immediately understandable?

### Coherent
Does the whole experience feel like one product?

### Non-AI
Does it avoid looking like an AI-generated template?

### Meaningful
Does every animation communicate something?

If not, iterate.

# Production Phase — Only After Approval

After the visual mockup is approved, harden the project for production.

Priorities:

## Performance — 5/5

- Core Web Vitals;
- optimized images;
- minimal JS;
- efficient animation;
- lazy loading;
- reduced-motion support;
- careful 3D/WebGL usage;
- strong mobile performance.

## SEO — 5/5

- semantic HTML;
- metadata;
- canonical URLs;
- sitemap;
- robots;
- Open Graph;
- structured data where appropriate;
- internal linking;
- indexability;
- Insights/article architecture;
- Italian/English URL and metadata strategy.

## Accessibility — 4/5

- keyboard navigation;
- focus states;
- contrast;
- semantic landmarks;
- labels;
- alt text;
- reduced motion;
- screen-reader compatibility.

## Mobile — 4/5

Mobile is a first-class experience.

## Animation — 3/5

Animation supports meaning and does not compromise usability or performance.
